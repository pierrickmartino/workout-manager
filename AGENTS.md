# Repository instructions for coding agents

Read `CLAUDE.md` for the repository map, `CONTEXT.md` for domain terms, and the relevant files in `docs/adr/` for decisions before changing behavior. Check the diff against `REVIEW.md` before finishing. These files are the source of truth; do not restate or override their rules here.

For model handoffs and the Matt Pocock skills workflow, see `docs/development/model-workflow.md`. Select a model for each session. Keep the issue, base commit, tests, and review findings in the handoff so another tool can continue without chat history.
