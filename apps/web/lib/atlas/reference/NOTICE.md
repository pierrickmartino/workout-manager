# Reference muscle-map artwork — attribution

`male-body.svg` and `female-body.svg` (and the `reference-data.ts` path data derived from them)
are the anatomical muscle-map artwork from
[Olkre/Sasha-s-Body-Map](https://github.com/Olkre/sasha-s-body-map).

**Used with the author's permission.** The repository owner contacted the author, who granted
permission to use this artwork in this project. This NOTICE records that grant and the
attribution; keep it alongside the assets. If the upstream project later publishes an explicit
open-source license, cite it here.

The app renders these paths recolored by our own Muscle coverage data; the muscle-region → hue and
heat behaviour is ours. The artwork geometry is the author's.
